# Quickstart

The repository ships a **synthetic** registry, `examples/synthetic_registry/`, generated by simulation v2
(condition `E_pi100_education`, seed 1, which is never used in an evaluation). It has 2,350 events: 2,173
attempts recorded with form A and 177 completed suicides recorded with form B, as in Valledupar.

| Folder or file | Content |
|---|---|
| `registry.csv` | One row per event: `form`, `date`, the fields of the forms and `outcome` |
| `catalog.toml` | The concepts |
| `mappings/` | The **correct** declaration: form A without education in 2016; form B without f1, f2; f3–f5 single choice; f6 partial; education in 5 levels |
| `mappings_undeclared/` | A naive declaration (everything exact, one version), to show what the checks detect |

Run `python examples/quickstart.py`. The steps:

```python
import pandas as pd
import rabmv

data = pd.read_csv('examples/synthetic_registry/registry.csv', dtype=str, keep_default_na=False, na_values=[''])
y = (data['outcome'] == 'completed').astype(int)

schema = rabmv.Schema.from_folder('examples/synthetic_registry/catalog.toml',
                                  'examples/synthetic_registry/mappings')
harmonized = rabmv.harmonize(data, schema)                 # measured / missing / not measured, per case

naive = rabmv.Schema.from_folder('examples/synthetic_registry/catalog.toml',
                                 'examples/synthetic_registry/mappings_undeclared')
checks = rabmv.run_checks(rabmv.harmonize(data, naive), y, naive, data=data)
print(rabmv.drop_explained_pairs(checks).alerts())         # what the naive schema did not declare

eligibility = rabmv.evaluate_eligibility(harmonized, y, schema.catalog)
matrix = eligibility.matrix(harmonized)                    # eligible concepts, common resolution, NaN = not measured
model = rabmv.RabMVClassifier(missing='marginalize',
                              categorical_features=matrix.categorical_indices()).fit(matrix.X, y)
model.contributions(matrix.X)                              # exact additive explanation of every case
```

Against the naive schema the checks report: f1 and f2 constant in completed suicides (A, questions not
asked), f3–f5 never marked together (B, single choice), education missing in form A in 2016 (E) and f6
blanks (C). With the correct schema, education is marginalized where it was not measured, and f1–f6 are
excluded because they were not measured comparably in both classes.
